06 / Actualizare fără operațiuni zilnice

Este necesară doar configurarea inițială a sursei de prețuri și a publicării GitHub Actions.

  1. Fișierele au fost încărcate automat în repository-ul existent de pe GitHub.
  2. Păstrează Settings → Pages → Deploy from a branch → main / (root); GitHub Pages publică automat fiecare commit din main.
  3. În GitHub → Actions, verifică workflow-ul „ATLAS - ponderi SPY automate”. El rulează în zilele lucrătoare, actualizează fișierul JSON și declanșează publicarea din main.
  4. În secțiunea „Auto Feed” de sus, introdu o singură dată cheia personală Twelve Data; nu o publica în repository.
  5. Widgeturile se reîmprospătează prin TradingView, ponderile prin GitHub Actions, iar variațiile ETF se încarcă automat când ai pagina deschisă.

Atenție: GitHub poate întârzia execuțiile programate și poate dezactiva workflow-urile unui repository public după 60 de zile fără activitate. Ponderile sunt aproximări SPY ale S&P 500; nu sunt ponderi sectoriale oficiale NDX.

ATLAS / Market Rotation. Dashboard de observație, nu instrument de execuție. Widgeturi de piață de la TradingView; întârzierile și disponibilitatea datelor depind de exchange și de politicile furnizorului. Cotații posibil întârziate, inclusiv dacă pagina se reîncarcă.

Ponderi sectoriale SPY: State Street, data efectivă este afișată la calculator; fallback 20 nov. 2026. ETF-urile tematice pot deține aceleași companii. Nu interpreta culoarea sau volumului ca un semnal garantat. Politica datelor TradingView.
