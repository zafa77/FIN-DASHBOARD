06 / Cum îl folosești zilnic, gratuit

Fișierul este o pagină web statică. Widgeturile cer internet pentru date.

  1. Deschide atlas_market_rotation.html în Chrome sau Edge. Dacă scripturile sunt blocate local, publică pagina folosind pasul următor.
  2. Pentru un URL permanent: creează un repository public pe GitHub, încarcă fișierul redenumit index.html, apoi mergi la Settings → Pages → Deploy from a branch → main / root.
  3. Salvează adresa site-ului în bookmarks și deschide-o zilnic. Datele din widgeturi se reîmprospătează prin TradingView; ponderea SPX și calculatorul au actualizare manuală.
  4. Pentru contribuție intraday complet automată și ponderi NDX actualizate este necesară o sursă de date autorizată/API; această versiune gratuită nu pretinde că le oferă.

ATLAS / Market Rotation. Dashboard de observație, nu instrument de execuție. Widgeturi de piață de la TradingView; întârzierile și disponibilitatea datelor depind de exchange și de politicile furnizorului. Cotații posibil întârziate, inclusiv dacă pagina se reîncarcă.
