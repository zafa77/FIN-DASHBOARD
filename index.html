05 / Metodologie, surse și limite

Dashboardul este de observație și folosește date publice plus cheia ta privată Twelve Data.

ETF · Twelve Data

22 de ETF-uri pentru variație 1D, iar seriile zilnice pentru 5D și 20D. Cache în browser, loturi de 6 cereri cu minimum 75 secunde între ele, plafon estimat conservator 480 credite/zi per browser.

VIX · Cboe

Ultima închidere publicată, min / medie / max și poziția în intervalul ultimelor 30 zile calendaristice. Se reîmprospătează din GitHub Actions, fără credite Twelve Data.

SPX · State Street SPY

Contribuții estimate ca pondere sector × randament ETF, nu contribuții oficiale calculate constituent-cu-constituent. Ultima dată a ponderilor este arătată separat.

Codul este public pe GitHub, dar cheia API nu este publicată acolo. Este salvată local în browser. Limitele Twelve Data sunt pe cont: consumul din alte dispozitive nu poate fi controlat de acest site. Site-ul nu garantează prețuri în timp real sau drepturi de redistribuire comercială.

ATLAS / Market Rotation. Dashboard de observație, nu instrument de execuție. Widgeturi de piață de la TradingView; întârzierile și disponibilitatea datelor depind de exchange și de politicile furnizorului. Cotații posibil întârziate, inclusiv dacă pagina se reîncarcă.

Ponderi sectoriale SPY: State Street, data efectivă este afișată la calculator; fallback 20 nov. 2026. ETF-urile tematice pot deține aceleași companii. Nu interpreta culoarea sau volumului ca un semnal garantat. Politica datelor TradingView.
